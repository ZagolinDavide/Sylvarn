# Glossario
* Á/á: pronunciata con AA, lunga
* É/é: pronunciata con EE, lunga
* Í/í: pronunciata con II, lunga come "feel" inglese
* Ó/ó: pronunciata con OO, lunga
* Ú/ú: pronunciata con UU, lunga come "moon" inglese

* Æ/æ: pronunciata con É molto aperta
